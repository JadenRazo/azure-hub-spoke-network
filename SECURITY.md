# Security Policy

## Support status

This repository is an archived learning artifact. It has no maintained release line, deployment, or security-support commitment. Do not deploy it unchanged.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature if it is available for this repository. Otherwise, contact `contact@jadenrazo.dev` with a concise description, affected files, reproduction steps, and potential impact.

Do not include credentials, live subscription identifiers, or other sensitive data in a public issue. Reports will be acknowledged when possible, but fixes and releases are not guaranteed for this archived project.
